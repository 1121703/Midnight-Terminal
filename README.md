# 午夜終端 (Midnight Terminal) — 原創海龜湯推理系統

一款基於本地端大型語言模型（Local LLM）的互動式海龜湯情境推理終端遊戲。

本專案以 **Java** 實作，透過 HTTP Client 串接 **Ollama API**，提供打字機式串流輸出、階梯式提示、雙模型切換，以及自動進度保存等功能，讓玩家能與 AI 主持人進行互動式海龜湯推理。

## 🌟 核心特色

### 🤖 AI 原創情境出題

透過精心設計的 **System Prompt**，引導模型避開常見的經典海龜湯題目，動態生成多元的原創謎題。

題目類型涵蓋：

* 清湯
* 紅湯
* 黑湯
* 本格
* 變格
* 隱情型
* 場景型

讓每次遊戲都能產生不同的推理情境。

### 💬 低延遲串流輸出

使用 Java 原生 `HttpClient` 串接 Ollama Streaming API，將 AI 回應以串流方式逐步輸出，呈現類似打字機的互動效果，提升遊戲過程中的即時感。

### 🎯 嚴謹的是非問答機制

遊戲過程中限制 AI 主持人的回答內容，主要維持：

* `是`
* `不是`
* `無關`

避免 AI 在玩家推理過程中直接透露完整答案。

此外，系統會透過：

* `[SUCCESS]`
* `[GAME_OVER]`

等狀態標籤判定遊戲是否完成，並進行相應的結案處理。

### 💡 階梯式提示機制

玩家可以輸入：

* `提示`
* `hint`
* `我需要關鍵提示`

取得額外線索。

系統會根據遊戲進度向 AI 發送不同的提示要求，依序提供環境氛圍、關鍵物體或其他相關線索，在協助玩家推理的同時盡量避免直接揭露答案。

### 🧠 雙核心模型切換

遊戲啟動時可以依照需求選擇不同的 Ollama 模型：

| 選項  | 模型           | 特點        |
| --- | ------------ | --------- |
| `1` | `qwen3:1.7b` | 中文語意理解    |
| `2` | `gemma3:1b`  | 英文與一般邏輯推理 |

玩家可以根據語言及推理需求選擇適合的模型。

### 🎨 ANSI 終端彩色渲染

封裝自定義 `UI` 類別，利用 ANSI Color Codes 對終端機輸出進行視覺化設計。

不同資訊會使用不同的顯示方式，例如：

* AI 主持人回應
* 玩家輸入
* 提示訊息
* 警告訊息
* 故事類型
* 系統狀態

提升純文字終端遊戲的可讀性與操作體驗。

### 💾 持久化進度保存

透過 `MemoryStore` 管理遊戲對話紀錄，並將目前遊戲狀態自動保存至：

```text
current_save.txt
```

即使遊戲中斷，也能在重新啟動後載入先前的對話內容，繼續進行推理。

## 🛠 技術架構

### 使用技術

* **程式語言**：Java 11+
* **大型語言模型服務**：[Ollama](https://ollama.com/)
* **使用模型**：

  * `qwen3:1.7b`
  * `gemma3:1b`
* **HTTP 通訊**：Java 原生 `java.net.http.HttpClient`
* **API 類型**：REST API / JSON Streaming
* **資料保存**：Local File
* **終端機介面**：ANSI Color Codes

### 系統架構

專案採用模組化的 **OOP（Object-Oriented Programming）** 設計，主要由以下模組組成：

```text
Midnight Terminal
│
├── Mid_Project
│   └── 遊戲主流程與核心邏輯
│
├── OllamaClient
│   └── Ollama API 通訊與 AI 回應處理
│
├── MemoryStore
│   └── 遊戲進度與對話紀錄保存
│
└── UI
    └── 終端機介面與 ANSI 色彩顯示
```

## 🚀 執行說明

### 1. 前置需求

執行本專案前，請確認：

* 已安裝 **Java 11 或以上版本**
* 已安裝 **Ollama**
* Ollama 服務正在執行
* 已下載至少一個支援的模型

Ollama 預設 API 位址為：

```text
http://localhost:11434
```

---

### 2. 啟動 Ollama

如果 Ollama 尚未在背景執行，可以透過以下指令啟動：

```bash
ollama serve
```

接著下載所需模型：

```bash
# 中文語意模型
ollama pull qwen3:1.7b

# 另一個可選模型
ollama pull gemma3:1b
```

兩個模型可以只下載其中一個，也可以全部下載。

---

### 3. 編譯與執行

進入專案目錄後，使用以下指令編譯：

```bash
javac -encoding UTF-8 Mid_Project.java
```

編譯完成後執行：

```bash
java Mid_Project
```

啟動後即可依照畫面指示選擇 AI 模型並開始遊戲。

## 🎮 操作指令

### 提問

直接輸入想確認的情境問題。

例如：

```text
死者是人類嗎？
```

AI 主持人會根據遊戲規則回答：

```text
是
不是
無關
```

---

### 取得提示

輸入以下任一指令：

```text
提示
```

```text
hint
```

```text
我需要關鍵提示
```

系統會提供目前遊戲的相關線索。

---

### 揭曉真相

如果想直接查看完整答案，可以輸入：

```text
揭曉真相
```

或：

```text
我想看湯底
```

系統將結束目前推理並顯示完整故事解答。

---

### 離開系統

輸入：

```text
exit
```

即可離開遊戲。

## 🎮 遊戲流程

```text

    │
    ▼

    │
    ▼

    ▼

```
